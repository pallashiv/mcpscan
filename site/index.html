Not a claim. Enforced.

Every report above runs entirely in your browser. It carries a policy that allows only its own code and blocks every network request — so even the deliberately hostile example can't send anything, anywhere.

mcpscan itself works the same way: it reads one file you point it at and never connects to anything. That's the whole reason a security tool is safe to point at a company's servers.

Verify it yourself: open any report above and check your browser's Network tab.
